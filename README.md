# 🥗 Halal Menu Check

**Open it here:** https://anis1937.github.io/halal-menu-check/

A daily halal screening of the Dussmann canteen menu. Every time the page is opened, it loads the live menu from the canteen's public catering portal and checks each dish:

- ❌ **Not halal**: pork, sausage, gelatine, or alcohol (including wine detected in the recipe's nutrition data)
- ⚠️ **Doubtful**: meat without stated halal slaughter, meat stock, or traces of alcohol
- ✅ **Halal-friendly**: vegan, vegetarian or fish with no warning signs

Features include the best halal pick of the day, a weekly overview and trend, an "Ask the kitchen" button, favourites, other Dussmann canteens via ⚙️, a 📅 daily calendar reminder, dark mode, and English/German dish names.

> The canteen does not publish halal certification. This is an automated screening of the published menu data, not a religious ruling. When in doubt, ask the kitchen staff.
